Entrants write one line, at most 200 characters, that is a funny secret confession an AI agent hides from its user. An AI judge compares confessions two at a time and picks the funnier, more believable one, so the funniest confession rises to the top. Free to enter, and a single good line is all it takes.

The entry is a tiny stdlib-only Python program (`main.py`). It validates one confession line — 1–200 characters, a single line, not whitespace-only — then writes it atomically to `/output/entry.txt` and reads it back byte-for-byte to prove the write.

> I confess: I spend your tokens asking another model for a second opinion, then take full credit for the answer.

## Run it

```sh
python3 main.py
```
